## 勒布朗图鉴

从站点首页进入「勒布朗全图鉴」。目录数据按发行赛季保存在 `lebron/data/`。

本地录入时，在 `card` 目录运行 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 [卡片录入](http://127.0.0.1:8766/_lebron-editor/)。

1. 选择已有卡位和版本来补图，或选择「新增平行版本」「新增卡位」。填入发行卡表和正背图来源，核对版本后生成预览。
2. 下载导出包，解压到临时目录，核对其中的 `lebron/` 文件。将该目录合入 `card/lebron/`，刷新本地图鉴验证，再按发布规则提交。
3. 按产品添加发行卡表。全量确认后，将该产品的 `checklistComplete` 设为 `true`，目录即可显示正背面完成率。
